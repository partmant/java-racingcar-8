# 자동차 경주

## 기능 목록

### 1.  입력 기능
- 사용자는 자동차 이름을 입력한다.
    - 자동차 이름은 쉼표(,)를 기준으로 구분한다.
    - 이름이 빈 문자열이거나 null이면 예외를 발생시킨다.
    - 이름이 5자를 초과하면 예외를 발생시킨다.
    - 중복된 이름이 존재하면 예외를 발생시킨다.
- 사용자는 이동 횟수를 입력한다.
    - 입력된 값이 정수가 아니면 예외를 발생시킨다.
    - 입력된 값이 음수이면 예외를 발생시킨다.

### 2. 경주 기능
- 0에서 9 사이의 무작위 숫자를 생성한다.
- 무작위 숫자가 4 이상이면 자동차가 전진한다.
- 무작위 숫자가 4 미만이면 자동차가 정지한다.
- 매 라운드 종료 시 결과를 출력한다.

### 3. 우승자 판별 기능
- 가장 멀리 이동한 자동차 이름을 우승자로 선정한다.
- 우승자가 여러 명일 경우 쉼표(,)로 구분해서 출력한다.

### 4. 출력 기능
- 각 라운드마다 자동차의 이름과 이동 상태를 출력한다.
    - 예: pobi : --
- 경주 종료 후 최종 우승자를 출력한다.
    - 예: 최종 우승자 : pobi, jun
### 6. 예외 처리
- 잘못된 입력값은 IllegalArgumentException을 발생시키며 프로그램 종료한다.
