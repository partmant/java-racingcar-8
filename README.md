# java-racingcar-precourse

---

## 📋 기능 목록

---

### 입력 (Input)
- 사용자로부터 자동차 이름을 입력받는다.
- 사용자로부터 시도 횟수를 입력받는다.

---

### 자동차 이름 (Car Name Domain)
- 입력된 문자열을 쉼표(`,`) 기준으로 분리할 수 있다.
- 자동차 이름이 비어 있거나 공백만 포함된 경우 예외를 던진다.
- 자동차 이름이 5자를 초과할 경우 예외를 던진다.
- 중복된 자동차 이름이 존재할 경우 예외를 던진다.
- 자동차 수가 2개 미만 또는 10개 초과일 경우 예외를 던진다.

---

### 시도 횟수 (Attempt Count Domain)
- 입력된 문자열이 비어 있거나 `null`인 경우 예외를 던진다.
- 입력된 문자열이 숫자가 아닐 경우 예외를 던진다.
- 입력된 숫자가 1 미만이거나 10을 초과할 경우 예외를 던진다.

---

### 자동차 이동 (Racing Domain)
- 각 자동차는 0~9 사이의 무작위 숫자를 부여받는다.
- 숫자가 4 이상이면 자동차가 전진하고, 3 이하이면 정지한다.
- 모든 자동차를 한 라운드 단위로 이동시킬 수 있다.
- 지정된 시도 횟수만큼 라운드를 반복할 수 있다.

---

### 우승자 결정 (Winner Domain)
- 가장 멀리 이동한 자동차를 우승자로 선정할 수 있다.
- 공동 우승자가 존재할 수 있으며, 여러 우승자를 반환할 수 있다.

---

### 출력 (Output)
- 각 라운드마다 자동차 이름과 이동 거리를 출력한다.
- 최종 우승자 이름을 쉼표(`, `)로 구분하여 출력한다.

---

### 예외 처리 (Exception)
- 모든 검증 실패 시 `IllegalArgumentException`을 발생시킨다.
